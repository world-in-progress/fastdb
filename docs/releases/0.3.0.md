# FastDB 0.3.0 release record

The coordinated release uses immutable tag `v0.3.0`, source
`ff097cca9c29cadc289e2a437f4720ecc56015c4`, for Python `fastdb4py`, npm
`fastdb4ts`, Rust `fastdb`/`fastdb-sys`, and the Core SDK.

0.3.0 adds zero-copy byte views in Python (`_payload_ext`, `ExternalBytes`,
`Payload.memoryview()`, `Access.memoryview()`), caller-owned external byte
inputs and caller-provided backing in Python and Rust, improves Core schema
reuse (`CompiledSpec` shared `RuntimeSchema`) and geometric `ValueArena`
allocation, and extends the C ABI from ABI-117 to ABI-118 with
`fdb_payload_v1_builder_value_external_bytes` across C++, Rust, Python, and
TypeScript/WASM. The [changelog](../../CHANGELOG.md) records the changes.

The verified candidate retains the 43-archive inventory: 35 Python wheels, one
sdist, four Core bundles, two Rust crates, and one npm tarball.
