# FastDB 0.3.0 release record — draft

0.3.0 adds zero-copy byte views in Python, caller-owned external byte inputs
and caller-provided backing in Python and Rust, improves Core schema reuse and
builder allocation, and exposes external byte inputs across C++, Rust, Python,
and TypeScript/WASM. The [changelog](../../CHANGELOG.md) records the changes.

The coordinated release covers Python `fastdb4py`, npm `fastdb4ts`, Rust
`fastdb` and `fastdb-sys`, and the Core SDK bundles from one source commit.
Package manifests and lockfiles carry 0.3.0. Core bundle metadata derives the
version from the package manifests.

## Validation

The `fdb_payload_v1` ABI uses version 1 and exports exactly 118 symbols. It
retains all 117 previous exports and adds
`fdb_payload_v1_builder_value_external_bytes`.
The release requires complete `tests.yml` and `release-artifacts.yml` runs for the
same final source on `main`, followed by exact-source consumer verification.
