## What 0.2.1 contains

FastDB 0.2.1 is the first release with native Windows x64 distributions: the Core SDK bundle `fastdb-core-0.2.1-x86_64-pc-windows-msvc.tar.gz` includes `fastdb.dll` and `fastdb.lib`, and the supported wheel set adds `win_amd64` alongside the existing Linux x86_64 and macOS arm64 targets.

The [MSVC correction](https://github.com/world-in-progress/fastdb/pull/37) renames shadowing JSON iterators and makes the compile-time graph/record branches exhaustive under warnings-as-errors. Beyond that correction, the release pins the MSVC execution charset to UTF-8 (`/utf-8`), adds explicit import/export annotation for consumers linking the static `fastdb_payload` archive (`FASTDB_PAYLOAD_STATIC`), moves compiled build plans allocation-free via an immutable shared index, and reduces allocation churn while compiling deep payloads with the 20,000-depth / 64 MiB limits unchanged. Payload layout and the 117-symbol `fdb_payload_v1` ABI are unchanged.

## Scope and downstream

Release evidence covers Linux x86-64, macOS arm64 and Windows x64; additional native platforms remain governed by [Issue 0001 D4](../issues/0001-portable-payload-deferred-capabilities.md#d4-guaranteed-platforms-beyond-linux-x86-64-macos-arm64-windows-x64-and-wasm32) until equivalent tests exist. Downstream consumers, including C-Two, can now pin this release; C-Two's own dependency move and release validation against the published Windows wheel remain downstream work outside this record.
