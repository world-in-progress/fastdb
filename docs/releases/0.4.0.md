# FastDB 0.4.0 release record

The coordinated release uses immutable tag `v0.4.0`, source
`af2790068d87d34f19061cb02f4d1c0e7ba224d0`, for Python `fastdb4py`, npm
`fastdb4ts`, Rust `fastdb`/`fastdb-sys`, Java
`io.github.world-in-progress:fastdb-java`, and the Core SDK.

0.4.0 adds first-class Java 17 LTS+ portable payload support: C++ Core
`FDB_PAYLOAD_CODEGEN_TARGET_JAVA` (`1 << 4`) code generation (`RenderJava.cpp`),
Rust `fastdb::CodegenTarget::Java`, the JNI Java runtime (`io.fastdb.payload`)
with bundled Linux x86_64 (Ubuntu 24.04, glibc 2.34+), macOS arm64 (macOS 11+),
and Windows x64 native libraries, and source-bound Maven Central packaging and
publication while preserving ABI-118 and `fastdb.payload.bin.v1` wire parity.
The [changelog](../../CHANGELOG.md) records the changes.

The verified candidate retains the 47-archive inventory: 35 Python wheels, one
sdist, four Core bundles, two Rust crates, one npm tarball, and four Maven
Central artifacts (main JAR, sources JAR, Javadoc JAR, and source POM).
