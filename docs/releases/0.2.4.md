# FastDB 0.2.4 release record — draft

0.2.4 addresses standalone native database ownership, numeric column cache
retention, and mapped backing lifetime. The design, prior measurements, and
validation boundary are in the [native memory report](../reports/0.2.4-native-memory.md).

The coordinated release covers Python `fastdb4py`, npm `fastdb4ts`, Rust
`fastdb` and `fastdb-sys`, and the Core SDK bundles from one source commit.
Package manifests and lockfiles carry 0.2.4. Core bundle metadata derives the
version from the package manifests.

## Validation

Local checks pass 403 Python tests, compileall, sdist/wheel builds, 45 native
ASan/UBSan tests, 21 Rust unit/integration tests and one compile-fail doctest,
58 TypeScript/WASM tests, and both 117-symbol ABI checks on macOS ARM64.
Installed wheels on CPython 3.10 and 3.13 each pass all 403 Python tests.
Six-cycle, 15,498,593-row read/write
probes with cyclic GC disabled show bounded memory in the native memory report.
The release requires complete `tests.yml` and `release-artifacts.yml` runs for the
same final source on `main`, followed by exact-source consumer verification.
