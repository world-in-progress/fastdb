## Release contract

- `fastdb4py`, `fastdb4ts`, `fastdb-sys` and `fastdb` use version 0.2.0; the Core/C ABI bundle belongs to the same release and source commit.
- Public payload ABI version 1 remains exactly 117 symbols. This release does not change payload schema, canonical identity or binary format.
- Native release evidence initially covers Linux x86-64 and macOS arm64; TypeScript uses the official wasm32 projection. Additional native platforms remain governed by Issue 0001 D4 until equivalent tests exist.
- Rust registry consumers use the matching platform Core bundle with `FASTDB_PAYLOAD_LINK_MODE=system` and an absolute `FASTDB_PAYLOAD_SYSTEM_LIB_DIR`. Checkout source mode is a separate development path.
- The release manifest records source SHA, hosted run identity, platform and artifact SHA-256. Registry jobs publish those verified bytes and treat an existing version as successful only after matching its artifact hash.
- Existing local candidate manifests remain historical. They are not rewritten as proof of this version or of a hosted run.

Fresh native builds use an explicit installed macOS SDK and C++ include path through temporary environment/build flags. No machine-specific path is committed as a project build default.

Native local runs used macOS arm64 and AppleClang. ASan ran with leak detection disabled, so no LeakSanitizer result is claimed. The x86-64 C11 header check was a compilation check, not an x86-64 runtime test.
